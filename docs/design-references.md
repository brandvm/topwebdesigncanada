# Design revision — Top Web Design Canada

This publication uses its own canada composition, local Google Fonts (manrope and dm-sans), selected Phosphor Icons 2.1.1 (MIT), and original vector editorial illustrations. Cover artwork is illustrative and does not depict agency client work or measured results. No reference-site copy, imagery, or paid template code is reused.

References inspected visually:
- [Top Brand Agencies](https://topbrandagencies.com/usa/): prominent agency names and digestible agency summaries.
- [Branding Agency Guide](https://brandingagencyguide.com/): comparison-first reading and a strong editorial type hierarchy.
- [Top Website Design Agencies](https://topwebsitedesignagencies.com/website-design-agencies-in-the-us): clear article context, concise introductions, restrained technical presentation.
- [Web Design Agency Guide](https://webdesignagencyguide.com/): expressive typography and spacious long-form reading.
- [WebAward archive](https://www.webaward.org/theblog/2026/): visible story hierarchy and editorial cover imagery.
- [BYQ Culture Exchange](https://www.byq.studio/template/culture-exchange): serif/sans contrast, confident typography, visual pacing; its live example uses Playfair Display and Inter Tight.
- [BYQ Nothing](https://www.byq.studio/template/nothing-template): distinct feature-to-grid hierarchy and clear visual separation between stories.
- [Mobbin: GitBook](https://mobbin.com/sites/sections/37fb52cf-9d27-4842-94ad-b49f6ea836c2): illustrated feature followed by article cards.
- [Mobbin: Dropbox](https://mobbin.com/sites/sections/04c5eed3-3d09-40c7-bfd4-a0b1b127d8a2): location-led story imagery and light card framing.
- [Mobbin: Clay](https://mobbin.com/sites/sections/b7ee345a-f244-49d7-bd36-d70371c517d1): editorial contrast and image-led story grids.

Fonts are self-hosted Latin WOFF2 subsets, with their licenses in public/fonts. Icons are vendored SVG paths with the MIT license in public/licenses; no icon font or JavaScript icon runtime ships to readers.
